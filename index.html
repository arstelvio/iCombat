Installer le jeu sur l'iPhone
  1. Touchez le bouton Partager de Safari
    (s'il n'est pas visible : menu ••• puis Partager)
  2. Choisissez Sur l'écran d'accueil, puis Ajouter
  3. Lancez le jeu depuis sa nouvelle icône : plein écran, hors ligne
Ou tournez l'iPhone pour essayer tout de suite dans Safari.
